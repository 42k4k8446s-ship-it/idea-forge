# Changelog

All notable changes to Idea Forge will be documented in this file.

## [0.3.0] - 2026-10-27

### Added
- Keyword search for ideas
- Search combined with category filters
- Search combined with "Want to build only"
- Edit existing idea text
- Edit existing idea category
- Save / cancel editing flow

### Improved
- Idea management workflow is now easier to use as the list grows
- Existing "Want to build" state is preserved while editing

## [0.2.0]

### Added
- Category filters
- "Want to build only" filter
- Delete a single idea
- Clear all ideas with confirmation
- Filter status display

### Improved
- Random picker respects the active filters
- Better empty states
- Improved mobile layout

## [0.1.0]

### Added
- Add new ideas
- Category selection
- Random idea picker
- Mark ideas as "Want to build"
- localStorage persistence
- Responsive idea card layout
